## 01　NumPy 和 Pandas 有什么用

对应笔记：[01_NumPy和Pandas有什么用.ipynb](01_NumPy和Pandas有什么用.ipynb)

### Python 列表的特点

Python 列表很灵活，同一个列表里可以同时放数字、字符串甚至其他列表。这种灵活性适合一般程序逻辑，但做大量数值计算时，每一个元素都需要经过 Python 对象层面的处理，速度和内存利用率不是它的强项。

### NumPy 解决什么问题

NumPy 的核心数据结构是 `ndarray`。数组中的元素通常具有相同类型，数据在内存中排列得更紧凑，许多运算由底层编译代码一次完成。

例如，数组 `temperatures * 9 / 5 + 32` 表达的是“对所有温度执行同一公式”。这种不手写逐元素循环的方式叫作向量化。它的价值不只是快，代码也更接近数学公式。

### Pandas 解决什么问题

现实数据往往不是纯矩阵，而是带字段名的表格：姓名是文字、成绩是数字、是否通过是布尔值。Pandas 的 `DataFrame` 能给行和列添加标签，并允许不同列使用不同数据类型。

可以简单地记成：

- `ndarray`：多维、规则、同类型的数值数据。
- `Series`：带索引的一列数据。
- `DataFrame`：多列 Series 按行索引对齐后形成的表格。

## 03　NumPy 数组属性

对应笔记：[03_NumPy数组属性.ipynb](03_NumPy数组属性.ipynb)

### 五个基本属性

| 属性 | 含义 | 示例 |
|---|---|---|
| `ndim` | 数组有几个轴 | 二维表是 2 |
| `shape` | 每个轴的长度 | 2 行 3 列是 `(2, 3)` |
| `size` | 元素总数 | `(2, 3)` 一共有 6 项 |
| `dtype` | 元素类型 | `int64`、`float32` 等 |
| `nbytes` | 数据区占用的总字节数 | 通常等于 `size * itemsize` |

### `(3,)` 不是 `(1, 3)`

`(3,)` 表示只有一个轴的一维数组。它没有“行”或“列”的概念。`(1, 3)` 才是一个二维数组，含 1 行 3 列。这一区别会影响转置、合并、矩阵乘法和广播。

### reshape

`reshape` 改变数据的观察形状，但元素数量必须保持不变。12 个元素可以变成 `(3, 4)` 或 `(2, 6)`，不能变成 `(5, 3)`。某一个维度写成 `-1` 时，NumPy 会根据总元素数自动推断。

## 04　NumPy 创建数组

对应笔记：[04_NumPy创建数组.ipynb](04_NumPy创建数组.ipynb)

### 根据数据来源选择创建方式

| 方法 | 适用情况 |
|---|---|
| `np.array()` | 已经有 Python 列表或元组 |
| `np.zeros()` | 需要指定形状的全零初始值 |
| `np.ones()` | 需要指定形状的全一初始值 |
| `np.full()` | 所有位置先填入同一个值 |
| `np.eye()` | 创建单位矩阵 |
| `np.arange()` | 已知起点、终点和步长 |
| `np.linspace()` | 已知区间和点的数量 |

### dtype 为什么重要

整数、浮点数和字符串的存储方式不同。`int32` 每项通常占 4 字节，`int64` 每项通常占 8 字节；浮点类型还能表示小数和 `NaN`。

类型范围不足会溢出，精度过高又可能浪费内存。数据量不大时不必过早优化，但应该养成检查 `dtype` 的习惯。

### empty 不是全零

`np.empty()` 只申请一块内存，不负责初始化，其中可能残留原来的内容。它适合随后会完整覆盖所有元素的场景，不能把它当成 `zeros()`。

## 05　NumPy 基础运算一

对应笔记：[05_NumPy基础运算一.ipynb](05_NumPy基础运算一.ipynb)

### 逐元素运算

两个形状相同的数组执行 `+ - * / **` 时，会对相同位置的元素分别计算。数组的 `*` 与数学课里的矩阵乘法不是一回事。

```text
[1, 2] * [3, 4]  -> [3, 8]
```

### 矩阵乘法

矩阵乘法使用 `@`。左矩阵形状为 `(m, n)`、右矩阵形状为 `(n, p)` 时，结果形状为 `(m, p)`。中间的两个 `n` 必须相同。

### 通用函数

`np.sin`、`np.sqrt`、`np.exp` 等函数能直接接收数组，对所有元素计算并返回同形状结果。这类函数通常称为 ufunc。

### 广播

广播允许不同形状的数组参与逐元素运算。NumPy 从 shape 最后一个维度开始比较：

- 两个长度相等，可以运算。
- 其中一个长度为 1，可以扩展。
- 两者都不满足，形状不兼容。

例如 `(3, 4) + (4,)` 会把长度为 4 的一维数组应用到每一行；`(3, 4) + (3, 1)` 会把每行对应的单值应用到该行全部 4 列。

## 06　NumPy 基础运算二

对应笔记：[06_NumPy基础运算二.ipynb](06_NumPy基础运算二.ipynb)

### 聚合运算

`sum`、`mean`、`min`、`max` 会把多个值汇总为更少的值。不指定 `axis` 时，它们通常面对整个数组。

`argmin` 和 `argmax` 返回的是最小值、最大值所在的位置，而不是数值本身。

### axis 的含义

对于二维数组：

- `axis=0`：折叠第 0 轴，也就是让不同行参与运算，为每列产生一个结果。
- `axis=1`：折叠第 1 轴，也就是让不同列参与运算，为每行产生一个结果。

不要只背“0 是列、1 是行”，更可靠的理解是“哪个轴被运算消掉了”。

### 累计值和相邻差

- `cumsum`：当前位置保存从开头累计到这里的总和。
- `diff`：当前位置保存相邻元素的差，结果在该轴上会少一项。
- `where`：返回满足条件的坐标，可用这些坐标取回原值。
- `clip`：把小于下限的值改成下限，大于上限的值改成上限。

## 07　NumPy 索引

对应笔记：[07_NumPy索引与迭代.ipynb](07_NumPy索引与迭代.ipynb)

### 基础索引

二维数组通常写成 `array[行, 列]`。冒号表示该轴全部位置：

- `array[1, 2]`：第 2 行第 3 列。
- `array[1, :]`：第 2 行全部列。
- `array[:, 2]`：全部行的第 3 列。
- `array[:2, 1:3]`：前两行、第 2～3 列。

### 布尔索引

`array > 8` 得到与原数组同形状的布尔数组。把它放回方括号，就能取出对应位置为 `True` 的元素。

多个条件需要写成：

```python
array[(array >= 6) & (array <= 11)]
```

不能写 `and`，因为 `and` 判断的是整个对象的真假，而 `&` 才会逐元素组合两个条件。

### 花式索引

使用整数数组可以按任意顺序取行或取具体坐标。它通常返回副本；普通切片通常返回视图。这个差异关系到修改结果时是否影响原数组。

## 08　NumPy 数组合并

对应笔记：[08_NumPy数组合并.ipynb](08_NumPy数组合并.ipynb)

### concatenate 与 stack

`concatenate` 沿已有轴延长数组。例如两个 `(2, 3)` 数组按 `axis=0` 合并得到 `(4, 3)`，按 `axis=1` 合并得到 `(2, 6)`。

`stack` 会创建新轴。两个 `(2, 3)` 数组 stack 后可能得到 `(2, 2, 3)`，新轴用来区分“这是第几个输入数组”。

### 一维数组的行列问题

一维数组 `(3,)` 使用 `.T` 后仍是 `(3,)`。如果需要真正的行向量或列向量，可以写：

```python
row = array[np.newaxis, :]     # (1, 3)
column = array[:, np.newaxis]  # (3, 1)
```

合并失败时，先比较输入 shape，确认除目标轴外的其他维度完全一致。

## 09　NumPy 数组分割

对应笔记：[09_NumPy数组分割.ipynb](09_NumPy数组分割.ipynb)

### 等分与不等分

`np.split(array, 3, axis=1)` 要求列数能被 3 整除。如果不能整除会抛出异常，这能及时提醒数据形状与预期不同。

`np.array_split` 允许不等分。例如 4 列分成 3 份时，可能得到宽度为 2、1、1 的三块。

### 指定切割边界

传入 `[1, 3]` 不是“分成 1 份和 3 份”，而是在下标 1 和 3 之前切开：

```text
[:1]  [1:3]  [3:]
```

这适合按照字段含义切分数组，例如把前两列作为特征，最后一列作为标签。

## 10　NumPy copy 与 deep copy

对应笔记：[10_NumPy复制与视图.ipynb](10_NumPy复制与视图.ipynb)

### 三种关系

| 写法 | 数组对象 | 底层数据 | 修改是否联动 |
|---|---|---|---|
| `b = a` | 同一个 | 同一份 | 是 |
| `b = a.view()` | 不同 | 通常共享 | 是 |
| `b = a.copy()` | 不同 | 独立 | 否 |

基础切片通常也是视图。因此：

```python
part = array[2:5]
part[:] = 0
```

可能会把原数组对应位置一起改成 0。如果希望保留原数组，应写 `array[2:5].copy()`。

共享不是坏事。处理几 GB 的数组时，视图可以避免昂贵的复制。关键在于编写代码时要清楚自己需要联动还是独立。

## 11　Pandas 基本介绍

对应笔记：[11_Pandas基础介绍.ipynb](11_Pandas基础介绍.ipynb)

### Series

Series 由值、索引和可选名称组成。索引不一定是连续整数，也可以是日期、编号或字符串。

### DataFrame

DataFrame 同时拥有行索引和列名。每一列有自己的 dtype，所以姓名列可以是字符串、价格列可以是浮点数、日期列可以是时间类型。

### 初次查看数据

- `head()` / `tail()`：查看开头和结尾的样本。
- `shape`：行数和列数。
- `columns` / `index`：字段与行标签。
- `dtypes`：检查数字、日期是否被错误读成字符串。
- `describe()`：数值列的计数、均值、标准差、分位数等。
- `sort_values()`：按照某一列的值排序。
- `sort_index()`：按照行或列标签排序。

## 12　Pandas 选择数据

对应笔记：[12_Pandas选择数据.ipynb](12_Pandas选择数据.ipynb)

### loc 和 iloc

| 方法 | 使用什么定位 | 切片终点 |
|---|---|---|
| `loc` | 行列标签 | 通常包含 |
| `iloc` | 整数位置 | 不包含 |
| `at` | 单个行列标签 | 不适用 |
| `iat` | 单个整数位置 | 不适用 |

选择时建议同时写出行和列：

```python
frame.loc[frame["score"] >= 60, ["name", "score"]]
```

这行代码从内到外读：先生成“成绩不低于 60”的条件，再选这些行，最后只保留姓名和成绩两列。

原视频中的 `ix` 会根据输入猜测标签或位置，容易产生歧义，后来已被移除。现在直接使用 `loc` 或 `iloc`。

## 13　Pandas 设置值

对应笔记：[13_Pandas设置值.ipynb](13_Pandas设置值.ipynb)

### 修改已有位置

修改与选择使用同样的 loc/iloc 规则：

```python
frame.loc[frame["score"] < 60, "passed"] = False
```

不要把它拆成 `frame["passed"][condition] = False`。后一种链式赋值可能先创建临时对象，修改是否回到原表不够明确。

### 新增列时的对齐

给一列赋标量时，每行得到同一个值。给一列赋 Series 时，Pandas 会根据索引标签对齐。Series 中没有对应标签的行会得到缺失值，多出来的标签不会凭空创建新行。

### 原地修改还是新表

明确返回新表通常更容易理解和调试：

```python
result = frame.assign(total=lambda data: data["a"] + data["b"])
```

原始 `frame` 保持不变，`result` 是增加新列后的表。

## 14　Pandas 处理缺失数据

对应笔记：[14_Pandas处理缺失数据.ipynb](14_Pandas处理缺失数据.ipynb)

### 先调查，再处理

`frame.isna().sum()` 可以统计每列缺失数量。进一步除以总行数，就能得到缺失比例。不要看到 NaN 就立刻删除整行，因为其他列可能仍然有价值。

### 删除

- `dropna()`：删除包含缺失的行。
- `dropna(subset=[...])`：只根据关键字段判断。
- `dropna(thresh=3)`：至少有 3 个非缺失值才保留。

### 填充

数值列可以根据含义选择均值、中位数或业务默认值。类别列可以填“未知”。时间序列可能适合前向填充或插值，但前提是相邻记录确实具有连续关系。

处理后应再次统计缺失值，并检查数据分布是否被填充值明显扭曲。

## 15　Pandas 导入导出

对应笔记：[15_Pandas导入导出.ipynb](15_Pandas导入导出.ipynb)

### 读取 CSV 时检查什么

1. 编码是否正确，中文有没有乱码。
2. 分隔符是否真的是逗号。
3. 表头是否被正确识别。
4. 缺失标记是否被识别成 NaN。
5. 数字、日期、类别的 dtype 是否正确。

大文件可以通过 `usecols` 只读需要的列，或用 `chunksize` 分块处理，避免一次占满内存。

### 导出格式

`to_csv(index=False)` 中的 `index=False` 很重要，否则普通的 0、1、2 行索引也会被写入文件，下一次读取时可能多出一列。

Pickle 能保留较完整的 Python 类型，但其加载机制不适合不可信文件。跨语言交换通常优先 CSV、JSON 或 Parquet。

## 16　Pandas 合并 concat

对应笔记：[16_Pandas合并concat.ipynb](16_Pandas合并concat.ipynb)

### 沿行拼接

多个表列结构相同时，可以 `pd.concat([...], axis=0)` 增加记录。Pandas 会根据列名对齐；某张表缺少的列会产生 NaN。

### 沿列拼接

`axis=1` 增加字段，此时根据行索引对齐。索引不一致时：

- `join="outer"` 保留索引并集，不匹配的位置产生 NaN。
- `join="inner"` 只保留所有输入对象共有的索引。

### 新版写法

原课程中的 `DataFrame.append()` 改为 `pd.concat([old, new])`。原来的 `join_axes` 可以用拼接后 `reindex(target_index)` 表达，而且目标索引更加明确。

## 17　Pandas 合并 merge

对应笔记：[17_Pandas合并merge.ipynb](17_Pandas合并merge.ipynb)

### concat 和 merge 的区别

concat 关心“沿哪个轴堆叠”；merge 关心“两张表用哪个键建立关系”。例如学生基本信息与考试成绩的列不同，但都包含 `student_id`，就可以通过该键合并。

### 四种常见连接

| how | 保留哪些键 |
|---|---|
| `inner` | 左右两边都存在 |
| `left` | 左表全部 |
| `right` | 右表全部 |
| `outer` | 两表并集 |

### 重复键为什么危险

如果左表同一个键出现 2 次，右表同一个键出现 3 次，合并后可能得到 2 × 3 = 6 行。合并结果突然变大时，应先检查键的重复情况。

可以使用：

- `indicator=True`：增加 `_merge` 列，显示记录来自两边、仅左边还是仅右边。
- `validate="many_to_one"`：声明预期关系，右表键不唯一时立即报错。
- `suffixes=("_left", "_right")`：区分两表中的重名列。

## 18　Pandas plot 画图

对应笔记：[18_Pandas绘图.ipynb](18_Pandas绘图.ipynb)

### 根据问题选择图表

| 想观察什么 | 常用图表 |
|---|---|
| 随时间或顺序的趋势 | 折线图 `line` |
| 不同类别的高低 | 柱状图 `bar` |
| 一个数值变量的分布 | 直方图 `hist`、箱线图 `box` |
| 两个数值变量的关系 | 散点图 `scatter` |
| 简单组成比例 | 饼图 `pie` |

### Pandas 与 Matplotlib 的关系

`Series.plot()` 和 `DataFrame.plot()` 底层使用 Matplotlib，并返回 `Axes` 对象。Pandas 负责快速把数据列映射到图形，Matplotlib 负责更细的样式、布局和保存。

绘图前还应处理缺失值，并确认坐标轴代表什么。图画得出来不代表表达正确：类别太多不适合饼图，时间顺序混乱会让折线图产生错误趋势，纵轴截断也可能夸大差异。

脚本把四种示例图保存为 `runtime_data/pandas_plot.png`。如果在桌面环境中希望弹出窗口，可以使用交互式 Matplotlib 后端并调用 `plt.show()`。

## 学完以后可以做什么

完成 18 集后，可以尝试一个完整的小练习：

1. 使用 Pandas 读取一份 CSV。
2. 检查 shape、columns、dtypes 和缺失值。
3. 用 loc 选择需要的行列。
4. 处理缺失和异常数据。
5. 用 merge 关联另一张表，或用 concat 合并多个月份文件。
6. 用 NumPy 完成标准化、矩阵或统计计算。
7. 导出清洗结果，并用合适的图表展示结论。

这套流程比单独记忆函数更重要。函数名称可以查文档，真正需要掌握的是数据形状、索引对齐、缺失含义以及每一步为什么要做。
