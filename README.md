# Python 第 18～110 集学习笔记与示例代码

本仓库根据黑马程序员 Python 入门课程 `BV1qW4y1a7fU` 的第 **18～110 集**整理。

内容从“数据类型转换”开始，覆盖基础语法、条件判断、循环、函数、五类数据容器、文件操作、异常与模块、JSON，以及 pyecharts 数据可视化，最后完成动态 GDP 柱状图。

每个知识章节都有独立文件夹，不需要在一个巨大的总文件中寻找内容。示例代码带有中文注释、运行结果提示、常见错误说明和同类知识横向比较。

## 运行环境

- Python 3.10 或更高版本
- 第 101～110 集图表案例需要 `pyecharts`

安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

## 如何运行

进入仓库：

```bash
cd python_course_18_110
```

运行一个章节：

```bash
python3 "01_基础语法_类型转换与字符串/第18-28集_基础语法.py"
python3 "05_列表元组字符串集合字典/第62-80集_数据容器.py"
python3 "11_柱状图与时间线/第108-110集_柱状图与时间线.py"
```

可视化章节运行后，会在相应章节的 `outputs/` 目录中生成 HTML 文件，使用浏览器打开即可查看交互图表。

文件操作章节会在自己的 `runtime_data/` 目录中创建练习文件，不会修改仓库外部的个人文件。

## 推荐学习方法

1. 按文件夹编号从前往后学习。
2. 运行前先阅读注释，并猜测每个 `print()` 的输出。
3. 运行代码，对照实际输出检查理解是否正确。
4. 修改变量和条件，观察程序进入不同分支。
5. 把案例关掉后重新手写，尤其是九九乘法表、ATM、账单备份和动态 GDP 图。

## 容器选择速查

| 类型 | 是否有序 | 是否可修改 | 是否允许重复 | 常见用途 |
|---|---|---|---|---|
| `list` | 是 | 是 | 是 | 需要频繁增删改的一组数据 |
| `tuple` | 是 | 否 | 是 | 内容确定后不希望被修改 |
| `str` | 是 | 否 | 字符可重复 | 保存和处理文本 |
| `set` | 否 | 是 | 否 | 去重、交集、并集、差集 |
| `dict` | 保持插入顺序 | 是 | 键不可重复 | 使用有意义的键查找数据 |
