## 运行方式

建议使用 Python 3.9 或更高版本。在当前目录运行任意章节，例如：

```bash
python3 "01_基础语法_类型转换与字符串/第18-28集_基础语法.py"
python3 "08_异常模块与包/第91-98集_异常模块与包.py"
python3 "17_正则表达式/第162-163集_正则表达式.py"
```

基础章节只依赖 Python 标准库。图表章节需要安装 pyecharts：

```bash
python3 -m pip install -r requirements.txt
```

如需运行真实的 MySQL 或 PySpark 示例，再安装可选依赖：

```bash
python3 -m pip install -r requirements-advanced.txt
```

MySQL 示例需要自行准备数据库并填写连接信息；PySpark 示例还需要兼容的 Java 环境。两类外部环境默认关闭，不影响阅读和运行文件中的基础示例。

## 建议的学习方式

1. 按目录编号依次学习，先阅读注释并判断代码会输出什么。
2. 运行示例，对照结果理解每一步的作用。
3. 修改变量、条件和输入数据，观察结果如何变化。
4. 关闭示例后自己重新写一遍，再尝试把多个知识点组合起来。

## 数据容器速查

| 类型 | 是否有序 | 是否可修改 | 是否允许重复 | 常见用途 |
|---|---|---|---|---|
| `list` | 是 | 是 | 是 | 经常需要增删改的一组数据 |
| `tuple` | 是 | 否 | 是 | 保存确定后不希望改变的数据 |
| `str` | 是 | 否 | 字符可重复 | 保存和处理文本 |
| `set` | 否 | 是 | 否 | 去重、交集、并集和差集 |
| `dict` | 保持插入顺序 | 是 | 键不可重复 | 通过有意义的键查找数据 |
